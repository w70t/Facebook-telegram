# Facebook ⇄ Telegram — بوت نسخ ونشر (يُدار بالكامل من تلغرام)

ينسخ المنشورات من **قنوات تلغرام**، ويرسلها إلى **بوت مراجعة** فيه أزرار،
وبعد موافقتك تُنشر على **صفحة فيسبوك**. كل الإعداد يتم **من داخل تلغرام**
— بدون تعديل أي ملفات. مصمّم للعمل 24/7 على **Raspberry Pi 5**.

> ⛔ تكامل X متوقف بالكامل: لا تسجيل دخول، ولا قارئ أو اتصال خلفي، ولا أزرار X.

```
قنوات تلغرام ─▶ بوت المراجعة (أزرار) ─▶ موافقتك ─▶ صفحة فيسبوك
```

> 📘 دليل الإعداد خطوة بخطوة: **[SETUP_AR.md](SETUP_AR.md)**

## المميزات
- **المصدر:** قنوات تلغرام عبر حسابك الشخصي، بدون أن تكون أدمن فيها.
- **كل شيء من تلغرام:** تسجيل الدخول بالرقم، فيسبوك، القنوات، الفلترة، والأدمنون — عبر أزرار.
- تسجيل دخول الحساب برقم الهاتف **مع رمز الدولة أو بدونه** (رمز افتراضي قابل للضبط) + دعم التحقق بخطوتين.
- **عدة قنوات** تُدار من داخل البوت.
- **فلترة كلمات:** أي منشور تلغرام يحتوي كلمة ممنوعة يُتجاهل تلقائياً.
- **دعم الألبومات:** عدة صور برسالة واحدة تُنشر **كمنشور واحد** على فيسبوك لا عدة منشورات.
- أزرار مراجعة لكل منشور: **✅ نشر** / **📄 نشر النص فقط** / **✏️ تعديل** / **❌ تجاهل**.
- **المنشورات المعلّقة تنجو من إعادة التشغيل** — أزرار المراجعة تبقى صالحة بعد أي restart.
- **تنظيف تلقائي** للمنشورات المهملة وملفاتها حتى لا تمتلئ بطاقة الـ SD.
- **🔄 تحديث ذاتي:** زر يسحب آخر نسخة من GitHub، يثبّت الاعتماديات الجديدة، ويعيد التشغيل.
- كل الإعدادات تُحفظ في `settings.json` **بكتابة ذرّية** مع نسخة احتياطية تلقائية.

## آلية العمل
1. **حساب تلغرام شخصي** يستمع للقنوات المصدر.
2. أي منشور جديد يمرّ على **فلترة الكلمات**، ثم يُرسل إلى **قروب المراجعة** مع أزرار.
3. عند ضغط **✅ نشر** يُرفع النص/الصور/الفيديو إلى **صفحة فيسبوك** عبر Graph API.

## البدء السريع

يتطلب المشروع **Python 3.10 أو أحدث** (جهاز Raspberry Pi الحالي يستخدم 3.13).
```bash
git clone https://github.com/w70t/Facebook-telegram.git
cd Facebook-telegram
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python configure.py   # مرة واحدة: api_id + api_hash + توكن البوت
python main.py        # شغّل البوت
```
ثم افتح البوت في تلغرام:
1. اضغط **🔑 تفعيل الملكية** ثم أرسل الرمز الذي يظهر في سجل التشغيل → تصبح المالك.
2. تظهر أزرار **⚙️ لوحة التحكم** و **🆔 معرّفي** و **🛑 إلغاء** ثابتة تحت خانة الكتابة.
3. اضبط بالترتيب: 🔐 تسجيل الدخول ← 📘 فيسبوك ← 📍 قروب المراجعة ← 📡 القنوات.

## أزرار الأوامر
| الزر تحت خانة الكتابة | الوظيفة |
|------|---------|
| ⚙️ لوحة التحكم | فتح لوحة التحكم |
| 🔑 تفعيل الملكية | المطالبة بملكية البوت أول مرة (5 محاولات كحد أقصى) |
| 🆔 معرّفي | معرفة معرّف المحادثة ومعرّفك |
| 🛑 إلغاء | إلغاء خطوة الإعداد الحالية |

تبقى الأوامر القديمة `/start` و`/panel` و`/claim` و`/id` و`/cancel`
متاحة للتوافق، لكن الاستخدام اليومي لا يحتاج إلى كتابتها.

## لوحة التحكم
| الزر | الوظيفة |
|------|---------|
| 🔐 تسجيل دخول الحساب | إدخال رقم الهاتف والرمز داخل تلغرام |
| 📘 إعداد فيسبوك | معرّف الصفحة + توكن النشر (يُتحقق منه فوراً) |
| 📍 تعيين قروب المراجعة | يجعل المحادثة الحالية مكان المراجعة |
| 📡 قنوات تلغرام المصدر | إضافة/حذف/عرض القنوات |
| 🚫 فلترة الكلمات | كلمات ممنوعة تُتجاهل منشورات تلغرام التي تحتويها |
| 👤 الأدمنون | إضافة/حذف أدمنين (للمالك) |
| 🌍 رمز الدولة الافتراضي | يُستخدم عند إدخال رقم بدون رمز دولة |
| 🔄 تحديث من GitHub | `git pull` + تثبيت الاعتماديات + إعادة تشغيل |
| ℹ️ الحالة | ملخّص ما تم إعداده |

## إعدادات إضافية (في `settings.json`)
تُضبط يدوياً عند الحاجة؛ للجميع قيم افتراضية معقولة.

| المفتاح | الافتراضي | الوظيفة |
|--------|-----------|---------|
| `fb_api_version` | `v23.0` | إصدار Graph API — ارفعه عند إنهاء دعم الإصدار |
| `max_media_mb` | `200` | أقصى حجم وسيط يُنزَّل |
| `pending_ttl_hours` | `48` | عمر المنشور المعلّق قبل حذفه تلقائياً |

## التشغيل الدائم على Raspberry Pi
```bash
sudo cp deploy/telegram-fb-bot.service /etc/systemd/system/
sudo nano /etc/systemd/system/telegram-fb-bot.service   # عدّل User والمسارات
sudo systemctl daemon-reload
sudo systemctl enable --now telegram-fb-bot
journalctl -u telegram-fb-bot -f
```
لتحديث الكود لاحقاً: اضغط زر **🔄 تحديث من GitHub** داخل البوت.

## التطوير والاختبارات
```bash
pip install pytest pyflakes
python -m pytest -q
python -m pyflakes *.py tests/*.py
```
الاختبارات لا تحتاج شبكة ولا حسابات، وتغطّي: الكتابة الذرّية للإعدادات والاسترجاع
من التلف، مخزن المنشورات المعلّقة، حدود نص تلغرام، تمييز أخطاء فيسبوك، وتعطيل مسارات X القديمة.

## تنبيهات
- ⚠️ استخدم **رقماً/حساباً ثانوياً** لحساب تلغرام الشخصي (أتمتة الحساب مخالفة لشروط تلغرام).
- ⚠️ احترم حقوق المحتوى وأضف مصدراً عند اللزوم.
- 🔑 **توكن Graph Explorer صالح ~ساعة فقط.** بدّله بتوكن طويل الأجل — الخطوات في [SETUP_AR.md](SETUP_AR.md#-إعداد-فيسبوك).
- 🔒 لا تُرفع إلى GitHub (مستثناة في `.gitignore`): `settings.json`, `pending.json`,
  `*.session`، وأي ملفات كوكيز X قديمة متبقية من إصدارات سابقة.

| `tests/` | اختبارات pytest بلا شبكة |
| `deploy/telegram-fb-bot.service` | خدمة systemd للتشغيل الدائم |
| `SETUP_AR.md` | دليل الإعداد المفصّل بالعربي |
